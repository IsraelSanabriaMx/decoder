## DECODER APP

This is a simple app to decode a long string in small fields. It is built with VanillaJS and HTML, nothing complex.
There is a textbox where the user pastes the long string, then the user clicks on the Decode button, and the data is rendered
below inside a table indicating Field, Name, Length, and value.


### STEPS TO CONFIGURE:
___

- Download files.
- Open index.html in your browser.


### HOW TO USE
___

- Open the app.
- Paste your long string in the text area.
- Click on the Decoder button.
- Decoded data is shown in the table below.
- Click on the Clean button if you want to clear all the values.
